# ✨ Flicksy
### Gesture-Controlled Interactive Photobooth

**Turn your hands into creative tools!**

Vision Verse is an interactive, gesture-controlled photobooth application that transforms a regular webcam into a creative digital playground.

Instead of relying entirely on a keyboard or mouse, users can interact with the screen through hand gestures — drawing, writing, experimenting with visual effects and capturing creative moments.

Built using Python and Computer Vision, Vision Verse combines real-time hand tracking with interactive drawing features and visual filters to create an engaging, touch-free experience.

---

## 🧠 How It Works

Vision Verse uses a computer vision pipeline to translate physical hand movements into digital interactions.

**The general workflow:**

1. **Webcam Input:** Captures live video frames.
2. **Image Processing:** Processes incoming frames using OpenCV.
3. **Hand Detection:** MediaPipe identifies the hand and tracks its landmarks.
4. **Gesture Interpretation:** Hand positions and movements are used to determine user interactions.
5. **Interactive Rendering:** The application responds by drawing, writing or applying visual effects.

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.12
- Git
- Visual Studio Code
- A working webcam
- Windows (commands below use PowerShell)

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project folder:

```bash
cd "Vision Verse"
```

### 2. Create a Virtual Environment

```powershell
py -3.12 -m venv .venv
```

### 3. Activate the Environment

```powershell
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

Upgrade pip:

```bash
python -m pip install --upgrade pip
```

Install the required packages:

```bash
python -m pip install -r requirements.txt
```

### 5. Verify the Model File

Ensure that the MediaPipe model file is present in the location expected by the Python code.

If the application expects the root-level file:

```text
hand_landmarker.task
```

If it expects the model inside `models/`, ensure the path is:

```text
models/hand_landmarker.task
```

## ▶️ Running the Project

Run the following scripts in order.

### Step 1 — Test Webcam

```bash
python 01_webcam_test.py
```

Verify that your webcam opens and captures video correctly.

### Step 2 — Test Hand Tracking

```bash
python 02_hand_tracking.py
```

Verify that your hand is detected and landmarks are tracked.

### Step 3 — Launch Vision Verse

```bash
python pinch_pop.py
```

Explore the available drawing modes, writing interactions and visual filters.

> Run each script separately. Close the previous webcam window before launching the next script if the camera remains occupied.

## 🔧 Troubleshooting

**1. Webcam not opening**
- Check camera permissions.
- Close other applications using the webcam.
- Verify the camera index in the code.

**2. Hand landmarks not appearing**
- Ensure your hand is visible in the camera frame.
- Improve lighting.
- Check that `hand_landmarker.task` is present at the expected path.

**3. Missing Python modules**
- Activate the virtual environment.
- Run `python -m pip install -r requirements.txt`.

**4. Application cannot find the model**
- Verify the model file location.
- Check the model path configured in the Python code.
